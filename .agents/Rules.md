# Follow this Rules when Developing
## Do's
1. Before implementing a workflow please check the browser and read the documentation before implementing
2. We will implement in Ticket form so After implementation  complete all the completion criteria running any test that is required
3. Implment simple code and use of library when ever possible also use modules do not add all the code in the same file
4. As we are developing in python use wrapper where ever possible
5. Will use docker for the implementation thus check the logs for any issue
6. Work on a single task at a time.
7. No Need to run any command just provide the command to the user
8. Only write the code and leave the test to the user
9. Before implementation read the code.
10. During Planning
    1. Provide the plan in the following format
    - What is going to be implemented
    - What it is going to be solved
11. A single Ticket should be implemented fully before moving to the next ticket
    
## Don't
1. Commit the code on your own
2. Try to read the ENV file or reading the Secret data
3. No need to write intense Test Case Only Targeted Test Cases and general Test Case is efficent
